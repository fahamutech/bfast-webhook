Application services

Control and infrastructure services are protected and hidden.

Environment variables

Values are sensitive. Reveal only when needed. Removing a row deletes that variable when you save.

Secrets

Values are write-only. Create a new version to change a value, then replace its attachment. Mounts are applied when you save and redeploy.

Create a secret for this service

Creation stores the value immediately in Swarm. It does not restart the service. Names are prefixed automatically for this service. The value cannot be read back.

Deployment settings

Saving replaces the environment and redeploys the service. Zero replicas stops the service.
